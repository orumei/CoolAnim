# CoolAnim

A small static site with animated gradient boxes.

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes this site whenever
changes are pushed to `main`. It copies `CoolAnim.html` to `index.html` in the
published site, along with the stylesheet and favicon.

To enable publishing:

1. Push the project files to the `main` branch of `orumei/CoolAnim`.
2. In the repository on GitHub, open **Settings → Pages** and set the source
   to **GitHub Actions**.
3. Wait for the **Deploy site to GitHub Pages** workflow to finish.

The published site will be available at
https://orumei.github.io/CoolAnim/.
